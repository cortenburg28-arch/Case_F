Put the real CSV files here. Everything in this folder except this note is
ignored by git, so nothing you put here is committed.

File names decide what each file is:

- `seniors`, `juniors`, `sophomores` in the name: that grade's form responses
- `project` in the name: the project list
- `roster` (or `gender`) in the name: Email Address, Gender
- `last` in the name: last year's final list
- `exclu`, `leader` or `trip` in the name: students to leave out
